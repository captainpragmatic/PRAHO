{% comment %} =============================================================================== TAB COMPONENT =============================================================================== One button of a {% tablist %}. A real tab is joined to its panel by id and its state is owned by the registered Alpine component `tabs`, which reads data-tab and the two class lists. A filter is an aria-pressed button whose state belongs to whatever holds the filter value: a delegated action (data_action, which swaps the two class lists) or the page's Alpine component (alpine_click, alpine_pressed, alpine_class). Every value is escaped here, once. {% endcomment %} {% load ui_components %}
