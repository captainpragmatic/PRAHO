{% comment %} =============================================================================== TOGGLE BADGE COMPONENT =============================================================================== A flag shown as a badge that flips it in place. The endpoint at hx_post answers with this control for the new state, which replaces this one (outerHTML); keep the same html_id so focus comes back to it (ui-actions.js, data-keep-focus). hx-sync drops a second click while one is in flight, since the endpoint inverts the flag, and hx-disabled-elt disables the control until the answer arrives. The name is the stable property label; aria-pressed and the badge text say the state. A locked control is disabled, shows locked_reason, and carries nothing that posts. Usage: {% toggle_badge active_label pressed=product.is_active on_text=active_label off_text=inactive_label hx_post=url html_id="active-x" %} {% endcomment %} {% load ui_components %}
