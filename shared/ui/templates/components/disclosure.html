{% comment %} =============================================================================== DISCLOSURE COMPONENT =============================================================================== The button that shows and hides a region the page already shows and hides. It never touches the region: the page's own state and the region's x-show stay the only owner. expanded_expr reads that state and toggle_expr flips it; controls is the region's id. Every value is escaped here, once, as in button.html. open_label shows while the region is open, closed_label while it is closed. Usage: {% disclosure "advanced-options" hide_label show_label expanded_expr="showAdvanced" toggle_expr="showAdvanced = !showAdvanced" %} {% endcomment %} {% load ui_components %}
