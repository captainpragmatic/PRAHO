# Settings whose EFFECT a test asserts — written, then observed through the code that reads them.
#
# The criterion is per TEST CLASS, not per file:
#
#   1. the class writes the key, and
#   2. the class uses a symbol imported from a module that READS that key, or reaches one within two
#      import hops — or, for a key whose only consumer is a template, the class requests a page.
#
# **This number went DOWN, from 77 to 56, and that is the correction rather than a regression.**
# The previous criterion combined "writes the key" and "reaches another app" across a whole FILE,
# never tying them to the same test. An independent review traced eight credits earned that way,
# including `virtualmin.rate_limit_qps`, qualified by an unrelated dashboard request elsewhere in a
# settings-permissions test file, and `audit.compliant_score_threshold`, whose qualifying test only
# checks that validation rejects a negative score and never touches compliance classification. Those
# tests do not exercise the setting's consumer at all, so "77 effect-tested" was not a supportable
# claim. 21 keys lost credit; none of them had a test that drove the setting anywhere.
#
# Scope is the class because that is how real tests are organised: the write often sits in `setUp` or a
# helper while each test observes. Reader reachability allows two hops because
# `test_localisation_api.py` drives `system.customer_date_format` through
# `apps.api.localisation.views`, which calls into `apps.common.localisation_services` — the module that
# actually reads it. Requiring the test to import the reader itself would reject a genuine effect test
# for using the front door.
#
# What the check still cannot do is inspect assertions: a qualifying class with every `assert` stripped
# keeps its credit. It measures that a test drove the setting INTO its consumer, which is far stronger
# than "the file mentions both", and still not a proof of coverage. Reading the test is what settles it.
#
# A ratchet. Removing a key requires saying why, in the same commit — which is how the eight false
# credits were found rather than quietly dropped.
#
# Recorded 2026-09-26 at 56 of 262 keys.
