# behaviour change. Reading the value back through SettingsService proves storage, which the
# other four checks in lint_settings_coverage.py already cover.
#
# This is a ratchet. `system.maintenance_mode` passed every wiring check while having no
# customer-facing consequence at all, which is why an effect dimension exists. Demanding an
# effect test for all 262 keys today would only teach people to bypass the gate, so the list
# records what IS tested and the check fails when something leaves it.
#
# Adding a key here requires the test that earns it. Removing one requires saying why, in the
# same commit.
