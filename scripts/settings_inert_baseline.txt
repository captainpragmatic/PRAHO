# Settings with no reachable production reader — check 6 of scripts/lint_settings_coverage.py
#
# Each key below is editable in the platform settings UI and has no production consequence. The
# pattern is identical in almost every case and is three lines long:
#
#     _DEFAULT_X = 100                                                   # what the code enforces
#     X = _DEFAULT_X                                                     # what live logic reads
#     def get_x(): return SettingsService.get_integer_setting("app.x", _DEFAULT_X)    # uncalled
#
# Live code compares against the module constant `X`. The getter that would consult the operator's
# configured value has no caller anywhere in production code. Check 1 (orphan settings) passes on
# all of them, because the key IS referenced in app code: inside the dead getter. That is the gap
# between a key being present and a key having consequences, and it is the same gap that let
# `system.maintenance_mode` ship with no customer-facing effect.
#
# Scope, stated because the first version of this check overclaimed. The criterion is static: a
# module-level, undecorated function, in a module with no dynamic dispatch, whose name appears in no
# production file that could import it, and whose keys no other production reader reads. Tests are
# excluded on both sides - a setting read back by a test proves storage, and a getter called only
# from a test still leaves the setting with no production effect. A finding is therefore "no
# reachable production reader found", not a proof of runtime unreachability.
#
# This file is a ratchet in both directions. A NEW inert setting fails the check at medium. A key
# here that becomes live fails at low until it is removed from this list, so the list cannot rot
# into a permanent excuse.
#
# Fixing one means calling the getter from the code that enforces the limit - which changes what the
# system accepts, so each is a deliberate change with its own test, not a sweep. Deleting the key
# from the catalog is an equally valid fix where the setting should never have been offered.
#
# Recorded 2026-09-26 at 56 of 262 keys.
