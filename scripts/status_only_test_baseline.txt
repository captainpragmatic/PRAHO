# Tests that request a page and assert only that it returned 200.
#
# Such a test raises the coverage number without verifying anything: the page could
# render none of what it computes and still pass. Two real examples from this repo -
# `reports.html` returning 200 with none of four aggregates rendered, and `vat_report.html`
# returning 200 with a 100x VAT error - were both invisible to status-only tests.
#
# Tests asserting 4xx or 3xx are NOT listed: for access control and redirects the status
# code is the behaviour under test.
#
# A ratchet in both directions. A NEW status-only test fails this check; a listed one that
# grows a real assertion fails until it is removed from the list.
#
# Fixing one means asserting a value the view computed - the figure on the page, the
# template chosen, the row written - not adding `assertContains(response, '<html')`.
